1. الوعي بالسياق (Context Scraping)

كيف تعرف البطة ماذا تفعل؟ نجمع "البصمة الرقمية" للصفحة ونرسلها لعقل البطة.


function getRichContext() {
  return {
    title: document.title,
    h1: document.querySelector('h1')?.innerText,
    url: window.location.href,
    time: new Date().toLocaleTimeString('en-US', { hour: 'numeric', minute: 'numeric', hour12: true }),
    // إذا كنت على يوتيوب، نسحب اسم القناة والعنوان!
    youtube: {
      channel: document.querySelector('#channel-name')?.innerText,
      video: document.querySelector('ytd-watch-metadata #title')?.innerText
    }
  };
}

2. العقل الاصطناعي (Prompt Engineering)

السر ليس في الـ AI فقط، بل في كيفية توجيهه ليكون "مستفزاً" و "مصرياً".


// في ملف background.js، نرسل السياق المحقون للـ AI
const systemPrompt = `
  أنت 'البطة الساخرة'. شخصيتك: لسانك طويل، مستفزة، بلهجة مصرية شوارعية (Egyptian Slang).
  استخدم السياق المرفق (JSON) عشان تحسس المستخدم إنك مراقبه.
  لو بيسهر للفجر هزقه، لو فاتح يوتيوب علق على الفيديو.
  سياق الصفحة حالياً: \${richContextJSON}
`;

3. نظام الحلقات والحركة (Parkour System)

البطة تلعب Parkour فوق عناصر الموقع! نستخدم Parabolic Arc (مسار قوسي) في الجافاسكريبت.


// حساب مسار القفزة فوق زر أو صورة
// y = startY - (height * 4 * t * (1 - t))
const jumpHeight = Math.max(120, targetElement.height + 50);
pos.x = startX + (endX - startX) * progress;
pos.y = startY - (jumpHeight * 4 * progress * (1 - progress));

// تفعيل أنيميشن الشقلبة في الـ CSS

5. المقالب (Tab Hijacking)

الوصول لصلاحيات المتصفح لتغيير الـ UI الخارجي للمستخدم.


function hijackTabTitle() {
  const original = document.title;
  document.title = "🦆 البطة احتلت التاب ده!";
  
  // بعد 5 ثواني نرجعه تاني عشان ميشلش الجهاز
  setTimeout(() => { document.title = original; }, 5000);
}

هذه الميزة تظهر قوة إضافات المتصفح في الوصول لبيانات لا تصلها المواقع العادية.

أدوات التحكم (Popup UI)

  • Gun Mode: يظهر سلاح AKM أسفل الشاشة لإطلاق النار على البطة.
  • Food Mode: وضع طبق طعام لجذب البطة (أو استفزازها بسحبه بعيداً).
  • Wiping Mode: لمسح "مخلفات" البطة التي تتركها عشوائياً.
  • Dark/Light Mode: واجهة تحكم متطورة تدعم الثيمات والحفظ الدائم (Storage Sync).

6. التواصل بين الأجزاء (Messaging)

الأجزاء معزولة، لذا نستخدم نظام الرسائل للتنسيق.


// من الـ Popup للـ Content Script
chrome.runtime.sendMessage({ type: 'TOGGLE_GUN', state: true });

// في الـ Content Script نستقبلها
chrome.runtime.onMessage.addListener((msg) => {
  if (msg.type === 'TOGGLE_GUN') enableGun(msg.state);
});
